# Contributing

## Development workflow

1. Create a focused branch for your change.
2. Keep commits small and descriptive.
3. Run the Maven test suite before opening a pull request.
4. Verify the Vite production build for web changes.
5. Update the README when user-facing behavior changes.

## Commit style

Use imperative, scoped messages such as:

- `feat: add member search`
- `fix: prevent duplicate loans`
- `test: cover return workflow`
- `docs: update deployment instructions`

Keep unrelated changes in separate commits.
